# Modelos 3D

Esta carpeta está reservada para modelos 3D locales (por ejemplo, `.glb`).

La versión actual no necesita modelos: todos los cuerpos se generan como
esferas con texturas y shaders propios, y los anillos de Saturno con una
geometría procedural. Si en el futuro se añaden modelos (sondas, asteroides
irregulares…), deben guardarse aquí y cargarse con rutas relativas, nunca
desde Internet.
